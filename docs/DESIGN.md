# Design read

中文视频学习工作区，NotebookLM 布局启发 + B 站明亮蓝色 + 初音未来二维动漫角色；Tailwind + native CSS，不声称使用官方 Material。使用 design-taste-frontend 的上下文规则。DESIGN_VARIANCE 6 / MOTION_INTENSITY 2 / VISUAL_DENSITY 4。

- 主品牌蓝色 `#00AEEC`，浅蓝白底色；正文链接使用更深的 `#007DA9`，主按钮文字使用深蓝以保证对比度。页面级深浅色切换。
- 面板 16px、输入与按钮 8px、图标按钮 8px；统一 Tabler 线性图标。
- next/font/local 加载 Next 自带的 Geist，中文回退 Microsoft YaHei；避免远程字体对本地启动的依赖。正文宽度和行高以长文阅读为目标。
- 首页左对齐导入动作、右侧初音插画；资料库展示真实标题和封面，不填充虚构笔记。手机缩小角色，不遮挡链接输入。
- 原始时间轴居中，来源左侧，助手右侧；手机顺序显示来源、正文、助手。平板助手移至下方。
- 标记平台字幕 / 本地 ASR / 本地检索 / 配置 LLM，避免把检索伪装为生成回答。
- 提供空、加载、队列、失败、重试、保存冲突、未保存与模型下载状态。
- 封面在后端允许的 CDN 地址上获取并缓存；无封面用视频图标表示来源。
- 初音插画采用真实二维线稿、赛璐璐色块、青绿双马尾、大眼睛与友好表情。首页较大角色建立视觉风格，助手区小头像与空状态呼应；时间轴正文不叠加角色。图片保存于本地，不依赖远程图床。
- Headless Edge 检查 1440px 与 390px、深浅色、编辑保存/还原、搜索、助手、SRT 下载和无横向溢出。截图在 `docs/screenshots/`。
