# ASR 审计（2026-10-15）

> 历史审计记录：v0.3.0 日常界面已改为默认自动校对与单一最终稿，操作与策略以 [当前说明](AI-PROOFREADING.md) 为准。
已直接检查代码和安装版本 faster-whisper 1.2.1 的函数签名，不凭印象使用选项。

| 项目 | 原有行为 | 证据与风险 | 改动策略 |
|---|---|---|---|
| 模型 | small，CPU int8 | tiny 样本错词明显；small 仍有错词，未测 CER | small 保留，不先宣称新默认；添加 medium / large-v3 / turbo |
| 解码 | beam_size=5，默认温度 fallback | 没有 beam=8 改善证据 | 5/8 可对照，仍默认 5 |
| 语言 | 自动，仅默认初始检测 | 中英混合后续片段可能不同 | 显式 zh / auto；逐段 multilingual 可选，非默认 |
| 提示 | 无 | 技术术语可能听写错误，未测术语准确率 | topic / initial_prompt / hotwords 可配置，不做自动字典替换 |
| VAD | 开启；阈值 0.5、静音 2000ms、padding 400ms | 尚无证据证明实际截断 | 保留默认，暴露开关/参数，记录 VAD 前后时长 |
| 音频 | FFmpeg 16k 单声道 PCM，没有降噪 | 标准输入；无证据需要激进降噪 | 保留重采样；不加降噪；保留原媒体和播放 PCM |
| 时间轴 | 模型 segment.start/end | 原稿不可覆盖；未做人工时间戳真值 | 每个 run 独立保存原时间轴，校对索引固定 |
| 缓存 | 视频/分 P 复用，不支持换模型 | 新模型无法独立比较；临时音轨删除 | 新增不可变 ASR run，重新转录另建 run，保留旧原稿 |
| 评测 | 缺人工真值 | 自动稿不能充当标准答案 | 用户确认没有现成真值；准备待核对样本和可执行 benchmark，结果未确认前不荐新默认 |

硬件：16 逻辑核心、31.7 GiB RAM；可用内存动态变化。CTranslate2 CUDA device count=0，nvidia-smi 不可用，VRAM 未知。CPU 大模型会较慢；内存预算提示是启发式，不伪装为实测。

校对只使用文字上下文时称为“文本校对建议”，不称为音频验证；所有 AI 修改先进入待复核列表，必须人工接受才能进入校对稿。原稿和原音频独立保留。
