## 准确率与验证边界

- tiny 中文样本出现明显听写错误，因此 tiny 仅建议快速功能检查。原稿仍保留，没有用 AI 悄悄改写。
- small 样本能形成可阅读的科普稿，但抽查仍有错词；没有人工逐字真值或 WER/CER 测量，不能宣称保证准确率。学习时应结合原视频核对，特别是数字与术语。更大模型可在新导入时选择。
- 两条公开视频的字幕接口均返回空字幕列表；真实“已有字幕”路径没有获得可用样本，只有 fixture 验证。API 不抓取浏览器登录信息；不能将“没有可访问字幕”宣称为“视频绝对没有字幕”。
- 短链接路径用可控重定向 fixture 验证；未找到可长期复现的真实短链接样本。
- 可选 OpenAI-compatible LLM 接口已实现，但未提供真实服务配置，未做外部 LLM 联调。默认本地检索已验证且不会发往云端。
- 大文件、长期连续运行、所有 B 站接入限制与字幕类型不在本轮覆盖。单 worker、1 GB 文件限制和首次模型下载依赖已明确。

## 发现并修复

1. HTTPX 对 302 调用 `raise_for_status()` 会阻止短链接解析；改为先识别允许的跳转状态，并在下一次请求前校验目标。
2. faster-whisper 1.2.1 与安装的 PyAV 19 存在 `metadata_errors` 参数兼容性问题；直接读取 FFmpeg 生成的标准 PCM，传入归一化浮点采样，真实 tiny / small 均通过。
3. 直接从浏览器读取平台封面在测试环境失败；改由后端验证 CDN 地址、限制图片类型和大小，并在本地缓存。
4. 启动停止需要覆盖 Python venv 和 Next 派生进程；以仅针对本次启动进程的树终止进行清理。
