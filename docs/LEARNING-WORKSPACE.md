# 学习工作区（v0.3.0）

日常只面对一份自动校对的最终文稿，操作见 [从零使用](GETTING-STARTED-ZH.md)。

- 左侧 Sources 显示来源信息与最终文字预览；文稿未完成时不显示未校对文字。
- 中间“来源问答”在最终稿完成后自动总结，可继续输入问题；“完整文稿”提供阅读、搜索、可选编辑与一键下载。
- 右侧 Studio 生成来源总结和思维导图，完成后保存为卡片，点击查看。
- 总结、问答、导图、引用和下载统一依据最终稿。旧来源版本的材料不混入当前列表。
- AI 校对与候选复查默认自动执行，不需要单独勾选或接受建议。未完成时阻止成品下载和学习生成。
- API 配置只需保存一次。Key 无效、余额不足、网络或结构错误会提示失败，停止自动重复付费尝试。

思维导图使用石墨色画布、曲线连线、原生布局缩放，支持全屏、拖动、滚轮缩放、适应窗口和键盘操作。当前一个笔记对应一个视频，不支持跨多个来源的长期聊天。

AI 返回引用必须指向真实存在的来源段落，结构错误不会保存。引用有效不等于语义正确，也不证明已经听音验证。原始数据和修正日志仅在后台保留用于恢复与排查。

验证方式：`scripts/final-workflow-ui-check.cjs` 使用合成浏览器夹具检查自动生成、无原稿/校对选择、成品下载、编辑同步、总结/导图/问答等待最终稿、失败恢复与手机布局；`scripts/mindmap-ui-check.cjs` 检查导图画布交互与文字缩放。测试不调用付费 API。真实文字联调记录见 [自动校对说明](AI-PROOFREADING.md)。
