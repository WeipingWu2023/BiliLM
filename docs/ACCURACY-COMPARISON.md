## 已完成验证

- 31 项自动化测试通过：17 项 MVP 回归 + 14 项准确率基础设施测试。覆盖版本/时间映射、raw 和执行元数据不可覆盖、校对先 pending、人工接受、过大改动拒绝、编辑冲突、迁移备份、不同模型独立 run、并发 worker 认领/租约/过期 token、指标已知编辑距离与时间偏差、同音频 hash 比较、禁自动大模型下载、结果提交事务回滚和本地音轨离线重转。
- 真实短文件回归：已有授权自生成英语 WAV，CPU int8 small。约 7.372 秒媒体，单次测得约 4.38 秒总处理、峰值进程 RSS 657,567,744 bytes（约 627 MiB）。这包括模型加载/解码/预处理的本次进程条件，**不是统计基准、模型独占内存或中文准确率**。
- 新 run 创建成功，旧原始 segments 逐项相等；模型 commit `536b0662742c02347bc0e980a01041f333bce120` 和权重 SHA256/运行时/FFmpeg/配置已存储。原媒体和 PCM 保留；HTTP Range 回放返回 206，三种文本版本各四种导出成功。
- Next.js 最终生产构建通过。桌面/手机、深浅色、原始/可读编辑保存还原、搜索、来源引用和 SRT 下载通过 Headless Edge 检查。额外验证音频按时间戳播放、人工校对显示差异/日志、raw 未改变及修改还原；初音主题保留。
- 未自动下载任何新大模型，未部署云服务，未启动昂贵模型矩阵。Linux/GPU 是可移植代码与部署文档边界，尚无该环境真实运行证据。

独立只读复查发现并修复：原稿/run/完成状态改为单一事务；播放文件带租约 token，防止过期执行覆盖已提交媒体；已保留音轨在 B 站联网前复用，从而支持离线重新转录。事务故障注入与离线复用测试均通过。

## 提升将如何被测量

固定同一音频与经人工审核的真值，分别按三种语言层执行单因素对照：small/medium/large-v3/turbo/SenseVoice；beam5/8；语言auto/zh/受支持粤语；无提示/术语提示；VAD默认/关闭/保守参数。记录全部有效默认值、模型和音频 hash、执行设备与量化。输出 CER、适用的英文 WER、术语遗漏/额外出现、片段遗漏/重复候选、时间边界误差、静音输出和人工核对的幻觉分类；资源和时间另列。

这些改造减少了“无法比较、无法重听、无法复现、静默修改”的风险，并提供更高质量候选；目前没有证据可断言已经提升了特定语言的识别准确率。OCR 仅可作屏幕术语辅助证据，不自动补进 spoken transcript。
