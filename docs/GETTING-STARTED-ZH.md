# BiliLM：从零开始使用

日常操作只有：**打开网站 → 粘贴链接 → 等待 → 阅读、提问或下载。**

## 安装与启动

1. 按 [README 安装说明](../README.md#下载与安装windows-11)安装 64 位 Python 3.12、Node.js 22/24、FFmpeg。
2. 下载 [最新版源码包](https://github.com/WeipingWu2023/BiliLM/releases)，右键全部解压，例如放到 `D:\BiliLM`。
3. 双击项目文件夹中的 **start.cmd**，首次会联网安装依赖。等待出现 `BiliLM: http://127.0.0.1:3000`。
4. 浏览器打开 **http://127.0.0.1:3000/**。保留启动窗口；重启电脑后需要重新双击 start.cmd。

如果 Python 版本不对，在解压目录打开 PowerShell，先执行 `py -3.12 -m venv .venv` 再启动。不要只点收藏的网址而不启动本地服务。

## 导入第一个视频

首页粘贴自己有权处理的 B 站链接或 BV 号，点击 **导入视频**。也可点击“导入已授权的本地文件”，选择 MP3、MP4、WAV 等音视频，最大 1 GB。

首次识别模型未缓存时需要下载。首次可以保留 small；更大的模型可在“转录质量与术语”准备，已安装模型直接选择即可。大模型不保证一定更准，CPU 处理可能更慢。

视频导入后会自动经历：读取字幕或本地识别 → AI 校对 → AI 复查 → 整理文稿。可以离开网页，但不要关闭启动窗口。

平台权限或音轨访问受限时，改用自己已有授权的本地文件；应用不绕过登录、付费、验证码或 DRM。

## DeepSeek 只设置一次

首次打开一篇笔记，在中间 **来源问答 → DeepSeek 设置** 输入自己的 API Key 和账户可用的模型名，点击 **保存并启用 DeepSeek**。之后无需再开启校对或接受建议。

已配置的电脑会直接自动处理。文字校对、专名检索、总结与问答可能产生 API 费用；文字会发送到配置的服务，原音频转录在本机进行。密钥保存在自己的私有 data 目录，不要共享给他人。

未配置时可先完成本地转录，但不会把未校对稿作为最终结果展示或下载；保存 Key 后会自动继续。

## 阅读、编辑与下载

点击 **完整文稿** 即可阅读自动校对后的内容，不需要选择原始稿、校对稿或可读稿。

点击右上角 **下载文稿**，直接下载 Markdown 全文，只有标题、来源和最终文字，没有附加原始时间轴。“其他格式”可选 TXT、SRT。

发现个别错误时可选 **编辑文稿 → 保存修改**。保存后阅读、下载、后续问答和学习材料使用同一份更新文字，不需要再点击整理。音频与模型设置放在文稿下方“音频与转录设置”中。

## 总结、问答与 Studio

最终文稿完成后，中间会自动生成总结；在底部输入问题即可问答。点击引用可以查看对应来源文字并定位文稿。

右侧 Studio 点击 **思维导图**，等待下方生成结果卡片出现，再点卡片查看。导图支持拖动、滚轮缩放、全屏、适应窗口和引用；Esc 退出全屏或关闭。来源总结也会保存为卡片。

最终稿更新后，旧来源的材料不混入当前结果；总结自动按新稿加载，导图需基于新稿生成。

## 已有笔记、失败和关闭

旧笔记打开后会自动补做新版校对，已完成的最终稿直接读取缓存，无需重新识别。刷新不会重复校对同一已完成版本。

AI 服务失败时明确显示文稿未完成，不拿初稿当成品。检查网络、Key 或余额后，到“完整文稿”点击 **重新处理**。任务不会因页面轮询无限重试付费调用。

关闭时在启动窗口按 Ctrl+C。备份时先停止服务，再复制整个私有 `data` 文件夹。升级前备份，将自己的 data 放入新版源码根目录，再完整运行 start.cmd。不要在运行中覆盖 SQLite，也不要公开自己的 data。

AI 校对仍可能出错，网页只能确认拼写，不能证明音频说过。机制、费用边界与验证记录见 [自动校对说明](AI-PROOFREADING.md)，排错见 [常见问题](TROUBLESHOOTING.md)。
