# BiliLM：从零开始使用

## 下载并启动

1. 先按 [README 安装说明](../README.md#下载与安装windows-11)安装 Python 3.12（64 位）、Node.js 22/24、FFmpeg。
2. 在 GitHub 项目首页点击绿色 **Code → Download ZIP**。下载完成后右键“全部解压”，例如放到 `D:\BiliLM`。
3. 打开解压后的项目文件夹。找到和 README 同级的 **start.cmd**，双击它。第一次安装依赖需要联网，请等待。
4. 启动成功会显示 `BiliLM: http://127.0.0.1:3000` 并自动打开浏览器。若未自动打开，手动输入 **http://127.0.0.1:3000/**。
5. 使用时保留启动窗口。重启电脑后，必须重新双击 start.cmd 再打开网址。这不是一个始终在线的公共网站。

如果 Python 指向其他版本，在项目文件夹地址栏输入 `powershell` 打开终端，执行 `py -3.12 -m venv .venv`，再启动。常见问题见[排错](TROUBLESHOOTING.md)。

## 导入第一个视频

1. 在首页输入框粘贴有权处理的 B 站视频链接或 BV 号，点击“导入视频”。支持标准视频链接、分 P 参数和受支持的短链接。
2. 第一次保留 **faster-whisper / small**。模型未缓存时会联网下载，视频较长时 CPU 转录需要耐心等待。
3. 也可以点击“导入已授权的本地文件”，选择自己的 MP4、MP3、WAV 等音视频，最大 1 GB。
4. 页面显示处理阶段与进度。可以离开网页，但不要关闭启动窗口。结束后，笔记进入“我的资料库”。
5. 平台不一定提供可访问字幕或音轨。看到登录、权限或平台限制错误时，改用你已有授权的本地文件；应用不会绕过限制。

## 选择更大的模型

展开“转录质量与术语”，选择 medium、large-v3 或 turbo，先查看安装状态。点击“下载所选模型”并明确确认，等待“已安装，可使用”。模型存在你自己的 `data/models`，源码不会自带开发者的缓存。

已有笔记要使用新模型，请进入文稿核对，点击“重新转录”；失败笔记可用“使用所选模型重新转录”。新转录会保留旧 run。直接打开资料库中的旧笔记只是读取缓存。

若需要一次准备所有高级候选，请先停止服务，在项目根目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\install-models.ps1 -IncludeSenseVoice`。这会下载 medium/large-v3/turbo，以及 SenseVoice CPU 依赖和权重，可能使用数 GB 网络与磁盘。完成后重新双击 start.cmd。作者已经下载的缓存不会包含在 GitHub 源码中。

普通话占主导可尝试中文；粤语或中英混合需按实际内容选择语言或自动检测。主题和术语只提供识别提示，不应强行替换内容。大模型不保证一定更准，CPU 可能更慢；先用短片段测试。

## 阅读、核对、编辑和导出

左侧 Sources 显示来源信息与文字预览。中间点击“文稿核对”，可切换：

- **原始稿：** 机器输出与时间戳，独立保存。
- **校对稿：** 对识别错误逐段修正；日志保留改动。AI 文本校对只是待审核建议。
- **可读稿：** 整理全文标点和段落；可自由编辑，保存后再导出。

输入搜索词定位文字。保留了音轨的转录可点击时间戳重听；旧来源没有音频时，应用无法凭空恢复。数字、术语、漏句和疑似重复应结合原音核对。

文稿右上角可复制或导出。**Markdown 可读稿只含标题、来源和完整整理文字，不重复附加时间轴。** SRT/JSON 用于需要时间戳的场景；缺少可靠映射的自由稿不能导出伪造 SRT。

## DeepSeek、问答与 Studio

1. 回到中间“来源问答”，点击下方 **DeepSeek 设置**。
2. 输入自己的 API Key、账户可用模型名，点击 **保存并启用 DeepSeek**。不要把 Key 发到 Issues 或聊天里。
3. 这会允许来源文字发送给服务方，可能产生费用，并自动生成/读取当前来源总结。可以在输入框提出问题，点击引用对照原文。
4. 右侧 Studio 点击 **思维导图** 或 **来源总结**。等待下方 **生成结果**出现卡片，再点卡片打开。
5. 导图采用深色画布。右上角“全屏显示导图”可铺满网页窗口，鼠标拖动可移动整张图，滚轮或右下角按钮缩放。“适应窗口”可找回移出视野的图。点击节点核对原句或导出。Esc 先退出全屏，再次 Esc 关闭。
6. 画布获得焦点后，方向键移动、`+/-` 缩放、`0` 适应窗口。手机可用手指拖动和缩放按钮。材料刷新后保留；AI 材料和本地原句提要有不同标记。

不想发给 AI 时，取消“使用已配置 AI”开关。没有 Key 仍可本地转录、核对和导出，本地提要只抽取原句，不冒充 AI 总结。当前问答不支持跨多个视频，也没有长期聊天历史。

## 真值标注

右上角“真值标注”是为客观 ASR 评测准备的工具，日常阅读不需要使用。最初普通话、粤语、中英混合各 3 个空槽位。导入授权音频，截取 60–180 秒，反复听音并独立填写参考稿；保存草稿不等于人工核对，必须由核对人明确确认。

不要把 ASR 或 AI 输出直接标为真值。模型比较需要一致音频、归一化规则和真实人工参考，详见 [评测说明](../benchmarks/README.md)。

## 关闭、备份、升级

- 关闭：回到启动窗口，按 Ctrl+C。下次重新双击 start.cmd。
- 备份：停止服务，再复制项目内整个 `data` 文件夹到自己的备份盘。这里包含密钥，请私密保存。
- 升级：先备份，再更新源码并完整运行 start.cmd。ZIP 用户把自己的 data 迁移到新版源码根目录；不要合并公开共享他人的 data。
- 网页打不开：先看启动窗口是否已成功；不能只点击收藏的网址而不启动服务。

所有相对路径均相对你自己的解压目录，不要求使用作者电脑的盘符或文件夹。
