# 音轨导入失败修复

用户实际视频 `BV1D3h46BEax:p1` 在下载阶段出现 `UNSAFE_MEDIA`。复现发现，公开 playurl 响应的主音轨为 `*.mcdn.bilivideo.cn:8082`，同时返回标准 HTTPS `*.bilivideo.com` 备用地址。原实现只检查主地址，拒绝之后没有尝试备用地址。

修复只调整音轨下载候选：读取 baseUrl/base_url/backupUrl/backup_url，去重后逐一沿用原有域名、HTTPS 和端口校验。跳过不支持的候选，遇到传输错误尝试下一有效候选。没有扩大域名/端口许可，没有启用任意重定向，没有绕过平台访问限制。断流残片在重试前删除，不与下一候选的数据拼接。失败提示不包含带签名的完整地址。

60 项后端测试通过，包含新增的两项：非标准主地址回退到安全备用地址；断流后重新下载、拒绝跳转到本地或其他未授权地址。真实用户任务重试后已完成：281 秒视频经备用地址下载、small CPU 转录，保存 193 段原始时间轴及 2057 字符可读稿；TXT/SRT/Markdown 三种导出均返回 200 且非空。这是导入功能验证，不是人工真值准确率验证。
