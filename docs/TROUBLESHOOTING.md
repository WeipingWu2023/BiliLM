# 安装与使用排错

先看启动窗口中的错误，再看项目 `data/` 中对应的 `api-error.log`、`worker-error.log`、`frontend-error.log`。分享日志前删除私人文字、用户名、签名 URL 和密钥。

| 现象 | 处理方式 |
| --- | --- |
| 重启后网址失效 / 拒绝连接 | 打开解压目录，双击 start.cmd，等待成功再打开 http://127.0.0.1:3000/ |
| Missing python/node/npm/ffmpeg | 安装 README 中的工具，重新打开终端；用版本命令检查 PATH |
| Python 版本不匹配 | 使用 64 位 Python 3.12；项目根目录执行 `py -3.12 -m venv .venv`；已有错误版本的 .venv 应先改名保留后重建，不要动 data |
| PowerShell 禁止脚本 | 双击 start.cmd（只对此次启动使用 ExecutionPolicy Bypass，不修改全系统策略） |
| npm.ps1 无法执行 | 手动安装时使用 `npm.cmd ci`；启动脚本已用 npm.cmd |
| Port 3000/8000 is occupied | 先尝试浏览器打开已有 BiliLM；关闭自己原有启动窗口再重启。不要随意结束未知进程 |
| Python/npm 安装网络失败 | 检查能否访问官方 PyPI/npm，修复网络后重新运行 start.cmd；不要下载陌生来源的一键包 |
| MODEL_NOT_CACHED / 模型未安装 | 在质量菜单显式下载模型；下载失败可重试并复用缓存；确认磁盘和模型托管站网络 |
| 只能用 small | medium/large/turbo 需下载到你自己的电脑；作者缓存不会随 GitHub 源码分发。下载后在已有笔记中点重新转录 |
| SenseVoiceSmall 不可用 | 它是实验后端，另需依赖和本地模型。先使用可用 Whisper；见 SENSEVOICE.md |
| CPU 转录很慢 / 内存不足 | 先测试短片段或 small/tiny；选择 CPU/自动并观察内存，不同时运行其他大模型。减少模型大小会改变准确率，需要核对 |
| CUDA_UNAVAILABLE / 缺少 CUDA 库 | 当前推荐选择 CPU。GPU 运行需匹配 CTranslate2/CUDA/cuDNN，不能仅凭有显卡就认定可用 |
| 403/412、权限、付费或音轨不可访问 | 平台限制不会绕过。尝试自己已获授权的本地文件；不保证每个公开视频都能导入 |
| 字幕读取失败 | 会尝试平台正常提供的音轨；音轨也受限时仍明确失败，不绕过限制 |
| 同一 URL 没有重新识别 | 资料库优先读缓存；进入完整文稿下方的音频与转录设置，用所选模型重新生成 |
| AI 401/余额不足/限流/模型无效 | 检查自己的 Key、余额和账户可用模型；按提示稍后重试。无需将 Key 发给作者 |
| AI 引用或结构错误 | 系统最多自动修正一次；仍无效则不保存。原稿不会被覆盖。引用有效也需要人工核对语义 |
| 点击导图后没有弹窗 | 先等右侧生成结果卡片出现，再点击卡片；下方会分别显示生成失败原因 |
| 导图只是原句结构 | 当前为本地模式；启用自己配置的 AI 后生成主题导图，本地提要明确不称为 AI |
| 导出不是最新文字 | 保存编辑后重新下载；旧下载文件不会被远程修改 |
| SRT 不可导出 | 自由编辑稿可能缺少可靠时间映射，确认最终稿已完成，或检查来源是否有可靠时间映射 |
| 音频无法回放 | 确认该 run 保留了音轨；旧记录没有保存的音轨不能自动恢复 |
| 最终稿一直未完成 | 检查 DeepSeek 设置、网络和余额；在完整文稿点击重新处理。失败不会因轮询无限重试付费调用 |

## 提交问题前

请记录 Windows 版本、Python/Node 版本、BiliLM release、选择的模型/后端、复现步骤、错误码。运行 `python scripts/doctor.py` 可查看只读硬件信息。无需提交 `data` 目录、真实 API Key 或整份私密文稿。

本项目当前仅支持本机单用户使用；没有公网登录系统。GitHub 仓库用于下载源码，不能用 GitHub Pages 代替后台服务。
