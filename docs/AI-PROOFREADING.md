# AI 语境校对：先校对，再整理

用于 ASR 把姓名、术语转成同音字的情况。原有流程保留，新增可选流程：

**字幕或 ASR → 独立原始稿 → AI 语境校对 → 可读稿 → 问答、总结与导图。**

这层校对没有听音频。网页能帮助核实专名拼写，不能证明视频说过这个词；AI 自信也不等于正确。

## 已有笔记怎么用

1. 在“来源问答 → DeepSeek 设置”保存自己的 Key 与账户可用模型名。
2. 打开笔记，进入 **文稿核对 → 校对稿**（可读稿页也有入口）。
3. 在 **先校对，再整理** 填主题，例如“乒乓球赛事与国乒运动员”；可选填已知词表，如“樊振东、王励勤”。词表不是强制替换表。
4. 可选勾选 **联网核对专名拼写**，再点击 **AI 语境校对并生成可读稿**。
5. 任务进入本地持久队列。可离开网页，但应保留启动服务。完成后校对稿和可读稿自动刷新，可查看自动修改数、待复核数、改动对照和拼写来源。
6. 待复核建议点击“重听”，再选择“接受”或“保留原文”。**接受待复核建议只修改校对稿；随后到可读稿点击“从校对稿整理”，再导出。**
7. 总结与导图使用校对稿。文字更新后原来的 AI 材料缓存失效，需依据新版本重新生成；旧导图不会偷偷改字。

没有原音频的历史记录会明确显示无法重听。不要把文本建议标成人工听音验证。

## 新视频自动校对

导入前展开“转录质量与术语”，勾选 **转录后自动 AI 校对，再生成可读稿**。可另外勾选联网核对。默认关闭，small/medium/large-v3/turbo/SenseVoice 原流程保留。

AI 未配置时提前提示。API 失败或结构不可靠时，仍保存成功的 ASR 原稿与本地可读稿，并提示稍后单独重试校对；无需再次识别音频。

## 自动应用规则

- 模型提出高确定性的局部建议，且为同音专名/术语，并有来源标题、用户词表或搜索返回的高权威拼写依据。
- 标题/词表明确列出的 3–6 字专名，允许单个普通话音节的前后鼻音差异，例如“樊正东 → 樊振东”。不进行任意相似音替换。
- 局部标点修正可以自动应用。
- 数字、低确定性建议、不满足上述规则的近音改动、无拼写依据的表达，全部保留为待复核。粤语不套用普通话同音/鼻音自动规则。

自动应用也可能出错，始终标注未经听音验证。原始稿完全独立，时间戳不变，不添加网页事实或新句子。来源本身说错事实时，不能用事实核查替代逐字转录。

## 联网能力与费用

普通对话调用不会自动执行搜索。本功能单独调用 [DeepSeek Search 官方接口](https://api-docs.deepseek.com/api/search/)，只支持配置为官方 DeepSeek 地址的服务。其他兼容接口仍可进行文字校对。

每次最多 **8 批文字请求 + 3 个候选词检索**，每批最多 80 段/6,000 字。每个目标段都处理；超预算会明确拒绝，不会悄悄只改前半篇。请求有超时，不自动无限重试。更长来源请先划分较短材料。

文字校对会向配置的提供方发送当前校对稿、标题、主题、词表及有限的邻接/开头上下文。检索只发送候选词、主题与标题，不上传音频或整段全文。两类调用都可能收费。Key 保留在本机私有 `data` 中，不包含在 GitHub 源码或校对日志中。

检索优先补充标题/词表尚未提供的姓名拼写，保留 HTTPS 链接、摘要、查询与时间。搜索失败或账户不支持时显示警告，继续进行有明确标记的文本校对，不伪称联网成功。搜索的权威等级是服务方的排序字段，不能作为音频证据。

## 保存、撤销与恢复

原始稿 / 校对稿 / 可读稿分别保存。改动日志记录前后文本、理由、自动或待复核状态、模型、拼写来源以及校对前的版本快照。

**撤销最近 AI 校对** 恢复该批之前的校对稿和可读稿。若校对之后已有人工编辑或接受建议，会阻止直接撤销，以免覆盖人工工作；旧文本仍在改动记录中。仅支持最近一批的直接撤销。

重复提交同一个运行中的任务会复用队列记录；新一批校对将旧的待复核建议标成已被取代，不堆叠重复建议。校对期间发生编辑时，版本检查阻止旧结果覆盖新稿。重启恢复采用原有 worker 租约，不能让过期 worker 写回结果。

## 本次验证（2026-10-18）

这不是准确率评测；没有完整人工真值，也没有把 AI 结果当成真值。

| 检查 | 实际结果 |
| --- | --- |
| 后端自动化回归 | 102 项通过，包括版本冲突、任务恢复、撤销、联网失败与原稿保护 |
| 浏览器夹具 | 校对提交、完成刷新、可读稿、撤销、导入开关依赖通过；不调用付费 API |
| 原有交互回归 | 来源问答/导出、导图全屏/拖动/缩放等通过 |
| 真实文字联调 | 单一授权乒乓球来源，166 段、1,449 字，使用已配置的 deepseek-flash |
| 首次联调 | 3 批校对、3 次检索；自动修改 10 段，51 段待复核 |
| 优化后同稿增量复测 | 再运行 3 批及 3 次检索；新增 3 处“樊正东 → 樊振东”，累计修改 13 段、48 段建议待复核 |
| 完整性 | 原始稿逐段一致；所有开始/结束时间戳一致 |

两次联调是开发验证记录，不能据此算 CER/WER、正确率或“修正了多少比例的错误”，也不是与原模型公平独立的准确率对比。私有稿件和音频没有随源码发布。

下一步应使用真值标注页，分别准备普通话、粤语与中英混合音频，经人工听音确认参考稿；对同一份 ASR 原稿比较校对前后 CER/WER、专名准确率、错误修改数和漏改数，尤其记录“本来正确却被改错”的案例。评测前不承诺提升 30% 或 50%。
