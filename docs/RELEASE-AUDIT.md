1. 字幕读取网络、权限或格式错误不再直接结束任务；保留失败类型，尝试平台正常提供的音轨。音轨也受限时仍失败，不绕过访问限制。新增允许回退与禁止越权的回归用例。

4. 重写 README、零基础教程，增加排错、贡献、安全、备份恢复、源码/素材许可说明与问题模板。
